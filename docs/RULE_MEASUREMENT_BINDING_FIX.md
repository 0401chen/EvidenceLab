# 自然语言实验结果与计数绑定修复

## 原因与范围

规则提取原来允许 `accuracy of N` 作为直接指标—数值表达，但没有继续检查 N 后面的名词。例如合成句 `We summarize mean accuracy of 37 runs.` 会被截成 `accuracy of 37`，产生值为 37 的实验。短引文确实存在于原文，因此仅检查引用 ID、字面值和引文连续性的校验无法发现这种语义归属错误。

本次仅修改 `backend/app/analysis.py` 的自然语言规则路径：在生成短引文之前，检查直接相邻的计数/配置名词，例如 runs、trials、epochs、iterations、seeds、samples、learning rate 和 dropout。存在明确配置角色时不生成实验结果，不猜测另一个数值。包含真实结果的其他匹配继续保留。

数字本身不在黑名单内，`accuracy 100%` 和 `accuracy was 1.0` 仍可提取。检测也不跨逗号或分号吞掉下一个配置子句；完整的括号计数单位与括号内的配置赋值区分处理。

过滤逻辑同时用于规范化数值匹配、原文字面引文定位和单句配置范围判断，避免同一数值既作为计数又作为结果时，引用选回被拒绝的计数位置。

表格、显式字段、候选采纳、原始证据、模型调用、问答、结论核验和报告逻辑不变。未放松引文校验或来源边界。没有新增依赖。

## 验证

- 新增 48 项合成回归：计数/配置拒绝、真实百分数与无百分号结果、F1/AUC/AUROC/RMSE/MAE/MSE、同句结果与重复次数、同值不同角色、引用和页码保留，以及候选 API 不覆盖旧记录。
- 同一组新回归在冻结的 bd5aacc 规则代码上：28 通过、20 失败；修复后：48 全部通过。
- 完整后端：469 通过，其中原有 421 项没有删除或改写。
- 前端：26 通过；生产构建通过；本地 HTTP 冒烟：19 项通过。
- 保存的真实论文证据在隔离库复测，原先两条计数型错误结果不再产生；人工实验、候选和历史报告载荷保持一致。原始 PDF、字段引文和页面预览通过检查。
- 所有验证均离线，没有真实模型请求。模型语义能力不据此宣称得到提升。

## 边界与部署

这是对明确计数角色的确定性拒绝，不是通用自然语言语义解析器。复杂表格自动归属、未知句式及模型生成的语义关系仍须独立验证。真实论文的本次规则重提取没有产生新的正确表格实验，不应将减少错误候选等同于自动提取完整性提高。

代码修复不会自动改变历史研究数据。错误旧记录仍在正式库时，正式页面和旧报告仍会显示它们。应另经确认，对指定记录建立可恢复审计、备份及事务校验，再考虑从当前实验集合移除；历史报告正文不可改写，只能标明其历史状态。

本次仅本地分支交付，尚未部署或推送。部署代码与清理旧数据属于两个需要分别确认的步骤。
