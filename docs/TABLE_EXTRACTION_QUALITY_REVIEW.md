## 已证实的断点

原始完整 PDF 再核对：GCN 14 页，目标 Table 2 在第 7 页；GAT 12 页，目标 Table 2 在第 8 页。
两页 PyMuPDF 原生 `find_tables()` 都返回零张表，但已有的 `_recover_percentage_dataset_tables()`
及 `_aligned_result_markdown()` 坐标恢复已经产生完整的 `caption_bounded_dataset_grid`，含表头、
逐行单元格坐标、原文 ID 和同页唯一表注关联。正式库已保存相同的可用结构，无需为本修复重新解析。

断点位于规则消费阶段，而非后续引文校验：

- `_table_experiments()` 寻找 accuracy 等指标列，而实际列是数据集名称。
- `_caption_matrix_experiments()` 处理数字参数列，要求数字列头、严格的单标量及特定表注格式。
  数据集名称列不满足合同；`in percent`、复数 `accuracies` 也不符合该路径的表注匹配。
- `_paired_protocol_table_experiments()` 处理明确裁剪协议的成对值，不能用于这两张表。
- `evidence_cells.table_cells()` 虽已能定位 ±/时间单元格，但主要服务模型来源检查，规则路径没有消费它们。
- 因而原规则直接返回空列表，尚未进入 `prepare_experiments()`，不能归咎于该验证器过滤正确结果。

## 最小改动

仅在 `backend/app/analysis.py` 增加两项内部函数，并在现有规则链中接入：

1. `_dataset_grid_experiments()` 只消费已经由坐标恢复确认的模型行—数据集列结构。
   复用已有 `_percentage_caption_metric()`，要求同论文、同页、唯一几何关联表注，并逐项核对
   Markdown、行名、列名、单元格原文、页码和坐标。重复列、重复行、缺失/错列及不明确表注拒绝。
   明确缺失占位符不生成结果，差值等派生行不冒充另一模型。训练配置列不当作数据集结果列。
2. `_dataset_result_cell()` 严格整格匹配标量、显式 ± 或带单位的时间注释。
   主值保持数值；完整单元格保存在 `table_context.value_cell_text`，整行原文保存在字段引文。
   ± 的数字和符号另存，`kind=unspecified`；不推定标准差、标准误或置信区间。
   时间另存，不推断训练/推理用途。未标明单位的括号对、范围、负误差及配置计数不接受。

没有修改 `_number()` 或既有 `100 runs` 防护，没有跳过 `prepare_experiments()` 或放松引用核查。
每条仍是 `review_required=true` 的规则结果；API 仅保存待审核候选，不自动替换人工实验。
数据集按列、模型按原表行顺序输出，保持确定性。缺失任务、划分和超参数不从附近段落猜测。
