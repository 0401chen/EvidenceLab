# 合成演示操作手册

材料为项目原创合成数据，不代表模型分析真实论文成功。新项目默认空库，不连接原项目数据。

1. 启动本项目，进入文献库，点击“载入演示”，确认合成提示。Study A/B/C 对应 `examples/` 三份原创文件。
2. 选择三篇文献，查看任一文献的原文证据，核查实验数值、字段和条件。
3. 在详情中“手动建立候选”，选择证据，填写字段和对应连续引文；保存后在候选列表审阅，确认才采纳；查看编辑历史。手工结果不能说成模型生成。
4. 进入对比分析。A/B 使用同一已报告设置；C 的划分不同，应提示条件差异。数值不同不代表科学冲突。
5. 点击矩阵数值或证据按钮回到原文；导出 Markdown/JSON；从已保存报告打开快照。
6. 问答选择本地证据检索，询问“GraphLite 的准确率是多少？”核对来源。本地模式不生成完整科研分析。
7. 核验输入具体说法，使用本地保守模式。显示证据不足是能力边界，不是已证明真或假。

用户可导入自己有权使用的、具有文字层的 PDF，检查页码、预览与高亮。仓库不含真实论文 PDF 或第三方论文截图，没有 OCR。

## 无费用隔离排练

```powershell
.\.venv\Scripts\python scripts/serve_offline.py --data-dir artifacts/rehearsal/data --port 8790
```

打开 `http://127.0.0.1:8790`。脚本禁止模型 HTTP 传输，仅使用独立排练库，不修改其他端口服务。停止该进程即可结束排练。

空库可重走合成演示，不依赖私人数据库。研究库先用 `scripts/backup_library.py` 备份到新目录，恢复在另一个数据目录验证，不能覆盖运行库；私人数据、响应和备份不得加入 Git。
