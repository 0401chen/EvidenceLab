# EvidenceLab 技术架构

浏览器 React/TypeScript → FastAPI → SQLite / 项目内原文文件。默认本机运行，外部模型仅在用户选择模型功能时通过 HTTPX 调用。

1. **导入与原文**：PyMuPDF 解析文字、页码及坐标；SQLite 保存证据与相对文件路径；SHA256 去重和路径边界保护；分页渲染在受限工作进程执行。
2. **实验与审阅**：规则或模型输出建立待审候选，也可从证据界面手动建立。字段绑定引文，检查连续原文、字面值、数值/指标/单位及实验归属。采纳、去重和编辑历史由 Store 管理，提取不直接覆盖已审阅记录。
3. **检索与问答**：本地词项检索召回证据；普通模型问答复用引文验证。模型回答通过引用检查后，另行调用模型核验来源支持关系。
4. **条件比较**：LangGraph 执行实验整理、条件对齐、差异分析和证据检查，节点主要是明确规则，不是多个独立科研智能体。条件不兼容时拒绝直接比较。
5. **结论核验**：已配置模型时默认模型语义核验；本地模式返回证据不足和候选来源；模型模式仍需检查归属和标签，不承诺自动科研判断可靠。
6. **报告**：保存实验与证据快照、来源和过程记录；导出 Markdown/JSON；过期快照可查看但不冒充当前结果。

| 模块 | 项目实现 |
|---|---|
| `store.py` | 持久化、原文路径、候选/审阅历史、报告快照 |
| `parsing.py` / `grounding.py` | 基于 PyMuPDF 的证据切片和严格引文匹配 |
| `providers.py` | 模型传输、结构化候选和字段证据校验 |
| `analysis.py` / `orchestration.py` | 条件比较和 LangGraph 编排 |
| `evidence_cells.py` | 普通提取复用的连续证据片段与显式表格单元格，保留指标/单位归属检查 |
| `pdf_preview*.py` | 隔离渲染、页码/坐标预览 |
| `frontend/src` | 文献范围、原文核查、人工候选、审阅和报告 |

第三方组件见[声明](../THIRD_PARTY_NOTICES.md)。本项目没有发明 PDF 解析、RAG 或状态图技术。

原文、数据库、历史记录均不随源码发布。文件读取拒绝越界；更新保留事务和并发控制。配置接口不返回密钥或完整敏感 URL。默认回环监听，无多用户鉴权，不应直接暴露公网。可选诊断默认关闭，没有下载 API，仅允许写入本地被忽略的 `artifacts/`。
