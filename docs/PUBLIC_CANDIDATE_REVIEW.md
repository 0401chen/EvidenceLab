## 手动创建与正常推送

1. 登录 GitHub，打开 [创建仓库](https://github.com/new)。
2. Owner 选 `0401chen`，名称 `EvidenceLab`，选 **Private**。
3. 不勾选自动 README、LICENSE 或 gitignore，创建一个空仓库。若名称已存在或远端不是空库，先停止，不要覆盖或强推。
4. 在本候选目录执行以下命令；不能在原项目中执行：

```powershell
git remote add origin https://github.com/0401chen/EvidenceLab.git
git ls-remote origin
git push -u origin main
git ls-remote origin refs/heads/main
```

`git ls-remote` 必须先确认为空仓库。推送不得使用 force。将远端 main SHA 与本地 `git rev-parse HEAD` 对照，并检查 LICENSE、README、第三方声明和单条根提交。
