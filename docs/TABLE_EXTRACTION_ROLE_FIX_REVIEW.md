## 实际修改

### 正向语义合同：`backend/app/table_roles.py`

坐标矩形不是科研角色证明。新函数 `dataset_contract()` 接受有限、可解释的正向形式：

1. 表注明确声明该轴是datasets/benchmarks；指定数量时必须与实际列数一致。
2. 表注明确列出对应列名，且同论文原文直接将这些名称定义为数据集/基准。
3. 不含列名的全表指标表注，还必须有同页原文明确引用该唯一表号并提及各自数据集，
   同时所有列名都能链接到明确的数据集声明。

只发现某个名称在论文其他地方出现、或者没命中配置黑名单，都不足以填写dataset。
角色依据及其原始引用加入字段证据链，不拼接引文，也不把未知轴变成已确认conditions。

全表指标必须满足完整的受限声明语法，单位及适用范围也在该语法内解释。
列特定的其他指标、混合单位、范围例外、未知缩写和无法解释的附加句均拒绝。
这不是扩大几个黑名单词：未被完整解释的剩余文字也会拒绝。
只额外允许明确命名现有方法/方法基名的特征数定义附注，不能将未知指标名称当作方法名；
合成的不同模型名、特征数和激活函数也覆盖了该路径，没有固定真实论文或数字条件。

### 提取与物理身份：`backend/app/analysis.py`

- 保留第一轮的严格单元格解析、原文、±及时间注释。
- 验证数值/方法单元格坐标及其父表边界，要求明确的页码与表注/表格物理框。
- 临时去重键包含论文、实际页码、表框、表注物理位置与原文、行框、列位置、值框和原始单元格；
  不使用仅由方法/数据集/指标/数值组成的全局键。
- 重复来源只选择首次有效来源输出结果；不修改来源对象，不改数据库证据ID，重复来源追加时原输出ID不变。
- 派生行只匹配明确的完整差值标签（如Difference、Absolute difference、Difference (B - A)），
  不再搜索方法名任意位置的change、ratio等词。

### 既有来源锚点：`backend/app/providers.py`

`_table_result_anchors()`可以将当前可用的角色声明提供给同一严格表格验证器。
它不扫描其他来源并借用其结果，不扩大模型检索范围或替换模型答案。
缺少角色依据或所选数字不属于对应主结果时，`_measurement_anchor_conflicts()`保守拒绝，
避免因锚点减少而放松原有检查；省略unit也不能绕过错误数据集或误差项检查。
本轮没有真实模型回归，不能据此宣称问答或第二阶段语义判断改善。
